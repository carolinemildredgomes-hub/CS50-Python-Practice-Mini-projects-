# Bank Account System 💰

## Overview
This project simulates a simple banking system using OOP.

## Features
- Create account with balance
- Deposit money
- Withdraw money
- Prevent overdraft

## Concepts Used
- Instance variables
- Methods
- Encapsulation
- Error handling

## Run
python bank_account.py

## Test
pytest test_bank_account.py
