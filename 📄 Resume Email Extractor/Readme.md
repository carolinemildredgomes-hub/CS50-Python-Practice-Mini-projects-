# 📄 Resume Email Extractor

A practical Python automation project designed for HR and ATS systems.

This project extracts email addresses from resume or CV text.

---

## 📌 Use Cases

- HR recruitment automation
- resume screening systems
- applicant tracking systems
- bulk profile processing

---

## 📌 Example

```text
Contact: caroline@gmail.com
→ caroline@gmail.com
```

- regex extraction
- text mining
- HR tech workflows
- automation scripting
