# Student Manager 🎓

## Overview
This project demonstrates a simple Student class using Object-Oriented Programming.

## Features
- Stores student name and house
- Validates input
- Clean string output

## Concepts Used
- Classes and Objects
- Constructor (__init__)
- Validation with ValueError
- __str__ method

## Run
python student_manager.py

## Test
pytest test_student_manager.py
