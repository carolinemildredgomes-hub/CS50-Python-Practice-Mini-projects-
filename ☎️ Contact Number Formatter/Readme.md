# ☎️ Contact Number Formatter

A professional Python project that formats raw phone numbers into standard readable form.

---

## 📌 Business Use Case

Useful in:

- HR databases
- customer management systems
- registration forms
- CRM tools

---

## 📌 Example

```text
1234567890 → (123) 456-7890
```
